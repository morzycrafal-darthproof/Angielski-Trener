# English Trainer

PWA do nauki angielskiego (poziom B1–B2, nacisk na angielski w IT):

- **Fiszki** z powtórkami w odstępach (algorytm SM-2) — talie IT, praca, ogólne + własne słowa
- **Gramatyka** — pytania z wyjaśnieniami po polsku, częściej wracają tematy z błędami
- **Mówienie** — rozpoznawanie mowy i zaznaczanie źle wymówionych słów
- **Dyktando** — odsłuch zdania i sprawdzanie zapisu

Działa offline, dane zapisuje w przeglądarce (localStorage). Bez frameworków.
Słówka, pytania i zdania można dopisywać w `data.js`.
